FarmSense Pro

A machine learning platform that predicts crop yield and forecasts crop price trends from soil, weather, farming, and market inputs, delivered as an interactive Streamlit dashboard.

Problem

Farmers plan planting, resources, and selling using unreliable, slow estimates, and most systems cover either yield or price, not both.

Approach

A shared pipeline: user input, preprocessing (encoding, scaling, feature creation), then a yield module and a price module. The team compared four models on an external agricultural dataset.

Resume Analyzer

An AI-powered platform that reads a resume, finds the best-fit career paths and the skills still missing, and answers career questions through a RAG chatbot.

Problem

Students and fresh graduates struggle to know which role suits their skills, what they are missing, and how to build a structured learning plan.

How it works

  1. Upload a PDF or DOCX resume and parse its text.
  2. A Groq-hosted LLM extracts name, contact details, education, skills, and certifications.
  3. A role matcher compares the skills against role requirements and returns the top three roles with match scores.
  4. Skill-gap analysis lists matched and missing skills for each role.
  5. A role-specific learning roadmap is generated.
  6. A RAG assistant, backed by a ChromaDB knowledge base and LangChain, answers follow-up career questions.

Screens

My role

I built the project end to end: the FastAPI backend, the resume parsing and skill extraction, the role matching, the RAG pipeline, and the web interface.

DocVault

DocVault is a secure document organizer for scanning, uploading, storing, and finding important personal documents such as ID cards, certificates, and insurance papers.

Open live demo   View code on GitHub

Problem

Important documents end up scattered across phones, email, and paper. They are hard to find when needed, and expiry dates are easy to miss.

What it does

Sign in your way

Google, Microsoft, Apple, or email, with a no-account demo mode to try it first.

Upload or scan

Upload images and PDFs, or capture a document with the device camera.

Auto-categorize

Personal ID, Education, Financial, Insurance, Medical, and Other.

Search by content

OCR extracts text from images, so documents can be found by name, category, or what is written inside.

Track expiry

Set expiry dates and see documents expiring in the next 30 days on the dashboard.

At a glance

A dashboard with total documents, expiring soon, and documents added this week.

Manage

Preview, edit details, download, or delete any document.

How it works

Upload or camera scan→Text extracted in the browser (Tesseract.js)→File saved to a private Supabase bucket→Details and text saved in PostgreSQL→Search and expiry alerts

Files are stored under each user's own folder. The extracted text is saved with the document record, which is what makes full-text style search across document contents possible.

Data model

categories

id, name, icon, color

documents

id, user_id, document_name, category_id, file_url, file_type, file_size, expiry_date, extracted_text, created_at, updated_at

Security

Row Level Security is enabled on all tables, and storage policies are per user, so one user can never read another user's documents. Protected routes require authentication.

Pages

Login, Signup, Dashboard (totals, expiring soon, recent uploads), Upload, Document Detail, Search with category filters, and Settings (account and storage usage). The layout is responsive, with a sidebar that becomes a mobile menu.

My role

I developed and deployed the app end to end: a React and TypeScript front end on Vercel, backed by Supabase for authentication, database, storage, and access rules.
